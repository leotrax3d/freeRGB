# Motherboard fan coverage

Generated by `scripts/cooling/fan-coverage.mjs` from LibreHardwareMonitor v0.9.6 (the pinned version) and freeRGB's own tables. Do not edit by hand; CI (`.github/workflows/fan-coverage-drift.yml`) fails when this file is stale.

Support is defined per fan-controller chip, not per board: a board is covered when its SuperIO/EC chip is. Columns:

* **Tier** — `verified`: audited register readback (Nuvoton separate-mode); `lhm-supported`: reduced duty only after a passed guided channel test, RPM plausibility fault; `read-only`: no usable control. Every controllable chip also offers the explicit per-channel `unrestricted` unlock (DECISIONS.md #14).
* **Status** — `hardware-verified`: accepted on real hardware within the stated scope ([COOLING_ACCEPTANCE.md](COOLING_ACCEPTANCE.md)); `simulated`: the chip family's register-level simulator passes the channel test, plausibility, fault-return and unlock tests (`crates/freergb-control/tests/chip_families.rs`); `unsupported`: no simulator family yet.
* **Community** — accepted hardware reports (`.github/ISSUE_TEMPLATE/fan-control-report.yml`, imported with `scripts/cooling/import-report.mjs`). A report is evidence for that board only and never promotes a chip to hardware-verified.

**Summary:** 64 LHM SuperIO chips, 56 with fan control; tiers: 17 verified, 39 lhm-supported, 8 read-only; status: 1 hardware-verified, 55 simulated, 8 unsupported; 42 EC board models (read-only).

## Linux hwmon drivers

## Simulator families

| Family | Capability | Quirk source |
|---|---|---|
| `nct67xx_separate` — Nuvoton NCT67xx/NCT5585D/NCT610xD, separate per-channel mode registers | verified | LHM Nct677X: per-channel FAN_CONTROL_MODE_REG and FAN_PWM_COMMAND_REG; audited readback in NativeNctEvidence. |
| `nct6701d` — Nuvoton NCT6701D (owner board, ASUS PRIME X870-P WIFI) | verified | LHM Nct677X 7-control layout; slower RPM settling as seen in the CHA_FAN2 calibration (COOLING_ACCEPTANCE.md). |
| `nct668x` — Nuvoton NCT6683D/NCT6686D/NCT6687D(-R), EC-style shared mode register | lhm_supported | LHM Nct677X: one manual-mode bitmask register for all controls; comment notes only fans 0, 1 and 3 respond on newer X870/Z890 boards. |
| `ite_it87_ext` — ITE IT86xx/IT87xx with 8-bit extended PWM registers | lhm_supported | LHM IT87XX: FAN_MAIN_CTRL_REG holds the output-mode bits of controls 0..2; the Gigabyte EC controller is disabled while writing. |
| `ite_it87_legacy` — ITE IT87xx with 7-bit PWM (no extended registers) | lhm_supported | LHM IT87XX without _hasExtReg writes value >> 1 into a 7-bit PWM field. |
| `fintek_f718xx` — Fintek F71878AD/F71889AD/F71882 | lhm_supported | LHM F718XX writes FAN_PWM_REG only; other Fintek chips report fans without controls. The chip's minimum-duty clamp is modelled as a limited duty range. |
| `winbond_w836xx` — Winbond W83627/W83667 | lhm_supported | LHM W836XX: controls 0 and 1 share primary control-mode register 0x04 (per-channel bit masks). |
| `asus_ec` — ASUS embedded-controller sensors | read_only | LHM EmbeddedController and Linux asus-ec-sensors expose temperatures and fan RPM only. |
