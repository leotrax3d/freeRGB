## Audit result

The five USB-HID detectors (IT8297 VID 0x048D: PIDs 0x8297/0x8950/0x5702/0x5711 and
Gigabyte 0x0414:0xa100, all usage page 0xFF89 / usage 0xCC via define
`REGISTER_HID_DETECTOR_PU(…, IT8297_UPG, IT8297_U)`) are inventoried; `identify()`
claims no device. The upstream IT8297 protocol (~11k lines controller with config,
flash and per-zone registers, feature reports) is not ported, and the audited
branch version sent fabricated packets. This family also carries mixed "HID +
other" transports elsewhere in the upstream folder.

| Upstream file/function | Notes for a future port |
|---|---|
| `GigabyteRGBFusion2USBController.cpp` (feature reports via `hid_send_feature_report`) | config/flash state machine, per-zone registers, firmware version read |
| `RGBController_RGBFusion2USB.cpp` | device-specific zone layouts |
| The same folder contains non-USB-HID SMBus controllers | not eligible under freeRGB policy |
