# Provenance

Upstream: OpenRGB, https://gitlab.com/CalcProgrammer1/OpenRGB,
Commit `bbc77470a7cba56af60989e54ba910d5ac66a3ac`.
License of every used upstream file: GPL-2.0-or-later (SPDX headers verified in
`AsusAuraMouseController.cpp/.h`, `RGBController_AsusAuraMouse.cpp/.h`,
`AsusAuraMouseDevices.h`, `AsusAuraUSBControllerDetect.cpp`).

The detector table is generated by
`scripts/openrgb/port-asus-aura-mouse-devices.mjs`.

This is the first ported sub-controller of the `AsusAuraUSBController`
family (the existing `modules/asus-aura-usb` crate keeps its inventory of
the remaining sub-controllers).

## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `AsusAuraUSBControllerDetect.cpp :: DetectAsusAuraUSBMice` + `REGISTER_HID_DETECTOR_IP` rows | `devices_table.rs / table.rs` | 9 of the 10 mouse detector rows: only devices whose `aura_mouse_devices` entry sets `direct = true`; `AURA_USB_VID 0x0B05`, interface 0, usage page 0xFF01 |
| `AsusAuraMouseDevices.h :: aura_mouse_led_maps` | `report.rs :: LED_MAPS` / `led_map` | Colour-slot layout per PID (Spatha X 5 slots, Chakram X 9 slots, Strix Impact III 2, AimPoints 1; underglow paints multiple slots) |
| `AuraMouseController.cpp :: SendDirect` | `report.rs :: direct` + `lib.rs :: frame` | 65-byte packets `00 51 29 <count> 00 <offset>` with 5 colours (R,G,B) each, one write per packet, no commit packets |
| `RGBController_AsusAuraMouse.cpp :: SetupZones` / `DeviceUpdateLEDs` | `lib.rs :: initialize` / `frame` | One LED per zone named `<zone> LED` in zone-id order; every update sends the whole colour buffer |

## Sub-controllers

| Sub-controller | Status | Devices |
|---|---|---|
| DetectAsusAuraUSBMice → AuraMouseController (native-Direct PIDs) | ported | 9 |
| Other Aura Mouse PIDs (Static-as-direct only, e.g. Gladius II, Pugio, TUF) | nicht portiert | no native Direct mode; Static is an effect mode upstream |
| Spatha X Dock (product string on PID 0x1979) | nicht portiert | direct=false upstream (dock colouring cannot be addressed per slot) |

## Changes

* Direct mode only; the effect modes (`SendUpdate` / `SaveMode`) are not
  exposed by the module API. Upstream sends no exit packets and none are
  sent.
* Upstream drains incoming packets before each effect update; the Direct
  path does not read, so the module does no reads.
* Zone/LED naming is identical (`Logo LED`, `Scroll Wheel LED`,
  `Underglow LED`); the wire packets carry zone colours exactly as
  upstream.
