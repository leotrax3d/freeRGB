## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `CorsairHydroPlatinumController.cpp :: SendMagic` | `report.rs :: magic` | 65-byte packet: report id 0, prefix 0x3F, byte 2 = (sequence << 3) \| command, 61 magic bytes at offset 3, PEC (CRC-8 poly 0x07) over bytes 2..64 at byte 64 |
| `CorsairHydroPlatinumController.cpp :: GetSequenceNumber` | `lib.rs :: next_sequence` | Monotonic sequence 1..31, wraps to 1, shared across every packet |
| `CorsairHydroPlatinumController.cpp` constructor | `lib.rs :: initialize` | MAGIC_1/2/3 with commands 1/2/3 in order |
| `CorsairHydroPlatinumController.cpp :: SetupColors` | `lib.rs :: frame` | Combined CPU block + fan colors sent in fixed 20-LED chunks (0-19, 20-39, 40-47) with commands 4/5/6, only for chunks that exist |
| `CorsairHydroPlatinumController.cpp :: SendColors` | `report.rs :: colors` | 20-LED chunk, BGR byte order at offset 3, PEC trailer |
| `CorsairHydroPlatinumController.cpp :: ~CorsairHydroPlatinumController` | `lib.rs :: shutdown` | HARDWARE_MAGIC_2/3/4/1 with commands 2/3/4/1 (hardware lighting restore) |
| `RGBController_CorsairHydroPlatinum.cpp :: SetupZones` | `lib.rs :: initialize_with_zones` | Fixed 16-LED 5x5 CPU block zone; a second 0..32-LED fan zone only on RGB-fan-capable models |
| `CorsairHydroPlatinumControllerDetect.cpp` | `devices_table.rs / table.rs` | All 13 detectors; the five Elite PIDs carry `rgb_fan: false` (upstream `no_rgb_fan_models[]`) |

## Changes

* Direct mode only; no firmware version read (upstream parses it from the first read).
* The optional initialize `zones` parameter sizes the fan zone; the CPU block is
  always 16 LEDs as upstream.
* Audit corrections over the first branch version: sequence counter is monotonic across
  all packets (was reset per packet), frames use the combined-color 20-LED chunking with
  commands 4/5/6 (was fabricated per-zone command layout), shutdown sends the upstream
  four hardware-magic packets (was a no-op), Elite models reject fan zones, device table
  and rgb_fan flags generated by script.
