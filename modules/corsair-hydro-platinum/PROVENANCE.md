## Changes

* Direct mode only; no firmware version read (upstream parses it from the first read).
* The optional initialize `zones` parameter sizes the fan zone; the CPU block is
  always 16 LEDs as upstream.
* Audit corrections over the first branch version: sequence counter is monotonic across
  all packets (was reset per packet), frames use the combined-color 20-LED chunking with
  commands 4/5/6 (was fabricated per-zone command layout), shutdown sends the upstream
  four hardware-magic packets (was a no-op), Elite models reject fan zones, device table
  and rgb_fan flags generated by script.
