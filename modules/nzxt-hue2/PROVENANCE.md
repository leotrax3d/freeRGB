# Provenance

Upstream: OpenRGB, https://gitlab.com/CalcProgrammer1/OpenRGB,
Commit `bbc77470a7cba56af60989e54ba910d5ac66a3ac`.
License of every used upstream file: GPL-2.0-or-later (SPDX headers verified across
`Controllers/NZXTHue2Controller`).

The detector table is generated by `scripts/openrgb/port-nzxt-hue2-devices.mjs`; the
per-device RGB channel counts come from the upstream `spawn_hue(info, name,
rgb_channels, fan_channels)` calls in the detect file.

## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `NZXTHue2Controller.cpp :: SendDeviceListRequest` / `ReadDeviceList` | `report.rs :: device_list_request` / `lib.rs :: initialize` | request `20 03`, 64-byte replies until `21 03` with bounded retries |
| `NZXTHue2Controller.cpp :: ReadDeviceList` switch on device ids | `report.rs :: parse_device_list` | id to LED-count table (0x10 ring = 8, 0x11 logo = 1, 0x13/0x14 = 18, 0x15/0x16 = 20, 0x1C = 16, 0x1D/0x1E/0x1F = 24) |
| `NZXTHue2Controller.cpp :: SetChannelLEDs` / `SendDirect` / `SendApply` | `report.rs :: direct/apply` + `lib.rs :: frame` | GRB planes, groups `22 10|group` + `22 A0` apply with fixed header bytes; every channel gets direct + apply even when empty |
| `RGBController_NZXTHue2.cpp :: SetupZones` | `lib.rs :: initialize` | one zone per RGB channel with device-derived LED counts |
| `NZXTHue2ControllerDetect.cpp` | `devices_table.rs / table.rs` | all 21 detectors with RGB channel counts (Hue 2 = 4, Motherboard/Kraken X3/RGB Controller = 3, 6-channel controllers = 6, others = 2) |

## Changes

* Direct mode only; fan speed, pump speed, temperature and brightness reads
  (0x67 02 etc.) and the 2023-effects paths are not exposed by the module API.
* Channels are limited to two 20-LED groups like upstream (devices with more than
  40 LEDs per channel are driven with the first 40, matching upstream behavior).
* Audit corrections over the first branch version: device id table fixed (0x10=8,
  0x11=1, 0x13/0x14=18, 0x15/0x16=20; previously wrong/missing), per-device channel
  counts taken from upstream spawn_hue calls (Hue 2 Motherboard was 2, Kraken rows
  were wrongly 3), missing device-list reply fails closed, one apply per channel
  including empty ones, upstream channel naming kept simple "Channel N", generator
  script added.
