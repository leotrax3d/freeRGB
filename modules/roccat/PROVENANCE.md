## Audit result

28 unique upstream detector rows (Burst, Burst Pro Air, Elo 7/9/7 SE/Elo x 2, Kone
Aimo/Pro/Pro Air/XP, Kova, Sense Aimo, Horde Aimo, Vulcan Aimo/TKL/120/121/122,
Aimox 40/60) are inventoried with interface/usage-page qualifications; `identify()`
claims no device. Each row dispatches to its own controller with its own framing
(e.g. RoccatBurst: control-mode feature report `0E 06 01 <direct> 00 FF`, direct
packet `0D 0B RGB…`, feature transport; Vulcan keyboards carry per-key tables with
the old/new protocol variants). The audited branch version had duplicated rows (56)
and served everything through output writes.

| Upstream file/function (example) | Notes for a future port |
|---|---|
| `RoccatBurstController.cpp :: SetDirectMode / SendDirect` | 6-byte control feature + 11-byte direct feature packets |
| `RoccatVulcanKeyboard*` | old (0x15) and new (0x0E 05) direct-mode packets, per-key key tables and matrix maps |
| `RGBController_RoccatElo / Kone / Kova ...` | per-device zones and LED counts |
