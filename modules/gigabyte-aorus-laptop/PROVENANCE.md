## Changes

* Direct mode only; hardware effect modes (Static/Pulse/Wave/...) and version read
  are not exposed by the module API.
* Audit corrections over the first branch version: replaced the fabricated init +
  eight 65-byte color frames with the upstream single 9-byte feature report, single
  LED layout, brightness default 0x19, keyboard-only support, interface/usage matching,
  generator script added.
