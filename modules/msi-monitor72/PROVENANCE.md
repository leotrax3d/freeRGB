## Changes

* Direct mode only; the upstream effect modes and DeviceSaveMode
  (store-to-flash) are not exposed by the module API, and streaming always
  keeps byte 167 at 0x00 exactly as the upstream Direct path does.
* The upstream 5 ms control-pipe idle after every feature write
  (MSI_MONITOR_PIPE_IDLE_MS) is omitted; the module API sends synchronously
  and has no timer facilities.
* Upstream drains stale replies before the version query; the module reads
  once and fails closed, which cannot see a buffered reply from a previous
  exchange that never happened.
* Circle/Ctype rows are driven as a plain line exactly as upstream notes;
  a custom per-model physical layout is still wanted.
* A transient branch version used an overlapping 1..=12 block fill loop;
  this was caught by the byte-exact test before any commit shipped.
