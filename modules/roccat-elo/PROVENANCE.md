## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `RoccatControllerDetect.cpp` (Elo 7.1 `REGISTER_HID_DETECTOR_IPU`) | `devices_table.rs / table.rs` | 0x1E7D:0x3A34, interface 3, usage page 0x0C, usage 1 |
| `RoccatEloController.cpp :: SendInit` | `report.rs :: init` + `lib.rs :: initialize` | Five 16-byte output writes: `FF 01`, `FF 02`, `FF 03 01`, `FF 04 00 00 000000` (SendDirect(0)), `FF 01` |
| `RoccatEloController.cpp :: SendDirect` | `report.rs :: direct` + `lib.rs :: frame` | 16-byte output report `FF 04` with the single RGB triplet at byte 4 |
| `RGBController_RoccatElo.cpp :: SetupZones` | `lib.rs :: initialize` | One "Headset" zone, single unnamed upstream LED gets the name "Headset LED"; the module layout needs a non-empty name |
