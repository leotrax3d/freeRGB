## Changes

* Direct mode only. The `GetMode`-style reads are not used (Direct
  refreshes each frame). Upstream has no effect modes beyond Direct.
* Upstream calls `hid_get_feature_report(dev, 3-byte buffer)` after each
  write; the module API call is made and its result discarded.
* No exit packets upstream, none sent.
