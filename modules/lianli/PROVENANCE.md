# Provenance

Upstream: OpenRGB, https://gitlab.com/CalcProgrammer1/OpenRGB,
Commit `bbc77470a7cba56af60989e54ba910d5ac66a3ac`.
License of every used upstream file: mostly GPL-2.0-or-later; note that the
`LianLiUniHubSLController` sources carry GPL-2.0-only SPDX headers — porting those
paths would constrain this module's GPL-2.0-or-later license to GPL-2.0-only.

The detector table is generated by `scripts/openrgb/port-lianli-devices.mjs`.

## Audit result

Only the true USB-HID detector rows are inventoried:

| Upstream row | Sub-controller | Status |
|---|---|---|
| Uni Hub - SL (0x0CF2, iface 1, page 0xFF72, usage 0xA1) | `RGBController_LianLiUniHubSL` | nicht portiert (audit; GPL-2.0-only Quellen) |
| Uni Hub - AL | `RGBController_LianLiUniHubAL` | nicht portiert (audit) |
| Uni Hub - SL V2 / AL V2 / SL V2 v0.5 | `RGBController_LianLiUniHubSLV2` | nicht portiert (audit) |
| Uni Hub - SL Infinity | `RGBController_LianLiUniHubSLInfinity` | nicht portiert (audit) |
| Strimer L Connect | `RGBController_LianLiStrimerLConnect` | nicht portiert (audit) |
| GA II Trinity (+ Performance) | `RGBController_LianLiGAIITrinity` | nicht portiert (audit) |

Nicht inventarisiert (blocked / nicht HID): die generischen
`REGISTER_DETECTOR`-Zeilen `Lian Li Uni Hub - AL` (AL10), `Lian Li Uni Hub`,
`Lian Li Universal Screen` benutzen kein USB-HID (custom udev/USB-Transport)
und folgen nicht dem Modul-Protokoll.
