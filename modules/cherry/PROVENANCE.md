## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `CherryKeyboardController.cpp :: SendKeyboardData` | `report.rs :: color_packet` | 64-byte packet: report id 4, command 0x0B at byte 3, length at 4, offset LE at 5/6, color data at byte 8, checksum over bytes 3.. in bytes 1/2 |
| `CherryKeyboardController.cpp :: SetKeyboardColors` | `report.rs :: colors` | RGB byte stream chunked at `CHERRY_KB_MAX_PACKET_SIZE` (0x36) with running offsets |
| `CherryKeyboardController.cpp :: ComputeChecksum` | `report.rs :: checksum` | 16-bit little-endian sum of bytes 0x03.. into bytes 0x01/0x02 |
| `CherryKeyboardController.cpp :: SendKeyboardModeEx` | `report.rs :: mode` | 64-byte parameter packet 0x06 with 0x55 marker, kept byte-exact (not used in direct mode) |
| `RGBController_CherryKeyboard.cpp :: SetupZones` | `lib.rs :: initialize` | Fixed 21x6 matrix, 126 LEDs (`CHERRY_MATRIX_CELL_COUNT`), R/G/B order, per-key LEDs |
| `RGBController_CherryKeyboard.cpp :: DeviceUpdateLEDs` | `lib.rs :: frame` | Single zone: RGB bytes of the whole matrix through `SetKeyboardColors` |
| `CherryKeyboardControllerDetect.cpp` | `devices_table.rs / table.rs` | All 25 `REGISTER_HID_DETECTOR_IP` rows with interface 1 and usage page 0xFF1C |

## Changes

* Direct mode only; hardware effect modes are not exposed by the module API.
* No `hid_read` reply handling: upstream waits for an echo after each write, the module
  transport performs the writes without blocking reads.
* No serial number read.
* Audit corrections over the first branch version: LED count fixed from 125 to the
  upstream 126 (21x6) and interface/usage-page matching added.
