## Audit result

36 detector rows are inventoried (upstream 38 minus the policy-excluded K70 CORE
keyboards), but `identify()` claims no device: the upstream protocol uses
`StartTransaction/SubmitData` block framing (0x30/0x31/0x32) with read validation,
software vs hardware controllers and per-key layouts; the audited branch version
sent fabricated `set_mode`/`direct` packets and 1025-byte block packets with wrong
payload structure.

| Upstream file/function | Notes for a future port |
|---|---|
| `CorsairPeripheralV2Controller.cpp :: StartTransaction/EndTransaction` | `write_cmd` 0x08 (wired) / 0x09 (wireless), `CORSAIR_V2_CMD_START_TX` |
| `CorsairPeripheralV2Controller.cpp :: SubmitData` | block write 0x30 header with length LE, 0x31 continuation, 0x32 stop |
| `CorsairPeripheralV2Controller.cpp :: SetMode/SubmitColors` | hardware/software controllers, per-key entries, brightness |
| `RGBController_CorsairV2Software/Hardware` | KeyboardLayoutManager layouts and zone sizes per device |
| Detect file | interface 1 + usage page 0xFF42 rows, wireless variants with any-page rows |
