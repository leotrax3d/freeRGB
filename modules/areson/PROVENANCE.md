## Changes

* Direct mode only: the Static mode with max brightness as used by the upstream
  Direct/default path; hardware effect modes are not exposed by the module API.
* Audit corrections over the first branch version: speed byte fixed to 0 in Static
  mode (was 2, which also corrupted the checksum byte), interface/usage matching
  added, generator script added.
* Upstream sends no initialization or exit packets.
