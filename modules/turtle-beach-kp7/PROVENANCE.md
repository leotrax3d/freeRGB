## Changes

* Direct mode only (upstream implements only Direct). No shutdown/exit packet
  exists upstream and none is sent.
* The upstream 50 ms keepalive thread (re-sends the last frame so the device
  stays in direct mode) is omitted: the module API has no timer threads.
  Frames sent by the host keep the device in direct mode while it is running.
* The macro/profile feature-report channel on report ID 0x11, the onboard
  effects and the docked USB hub (PID 0x503E) are not handled, exactly as
  upstream.
* Numpad key labels use plain names instead of the upstream `KEY_EN_*`
  constants (presentation only; wire behaviour is unchanged).
