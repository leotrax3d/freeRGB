X12 on interface 1, usage page 0x0008, usage 0x4B via EVGA_X12_* defines).

## Audit result

All 7 detector rows are inventoried, but `identify()` claims no device. The audited
branch version fabricated every packet builder (65-byte mouse, 40-byte X12, 136-byte
keyboard packets that match nothing in the upstream controllers):

| Upstream file/function | Notes for a future port |
|---|---|
| `EVGAKeyboardController.cpp :: SetLedsDirect` | per-key feature reports with `packet_map` offsets (4-byte entries), two different controller ID sizes (ID_4/ID_6), Z20 extra keys table |
| `EVGAKeyboardController.cpp` | mode/colour packets and version read via controller ID 7 feature reports |
| `EVGAMouseController.cpp :: SetLed` | single-LED feature report with index/brightness/speed + get-feature queries, wireless 10 ms packet delay |
| `EVGAX12Controller.cpp` | read/state machine (MODE/STATIC reports with per-LED brightness/colors), SendReport/GetReport |
| `RGBController_EVGAKeyboard.cpp` | 104-LED matrix map layout |
