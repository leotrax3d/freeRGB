## Audit result

The 38 upstream detector rows dispatch to 11 different controllers; `identify()`
claims no device. The audited branch version served all rows with three fabricated
generic packets (64-byte keyboard/mouse/direct builders without the actual framing).

| Upstream controller family | Notes for a future port |
|---|---|
| `CMMMController` (MM520/MM530/MM531...) | init packet `00 41 80`, colour status reads `00 52`, mode packets with per-zone bright/colors, buffer filled with 0xFF from byte 17 |
| `CMRGBController` / `CMARGBController` / `CMSmallARGBController` / `CMARGBGen2A1Controller` | ARGB controller protocols (LED strip controllers) |
| `CMMP750Controller`, `CMR6000Controller`, `CMMonitorController`, `CMGD160Controller` | own framings |
| `CMKeyboardController` + `CMMKControllerV2` keyboard rows | keyboard packet set (usage page 0xFF00) |
| `CMMM711Controller` / `CMMM712Controller` | mouse-specific packets (MM712 uses 0x5A 0x81 ... feature) |
