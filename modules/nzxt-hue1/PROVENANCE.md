## Changes

* Direct mode only; the 11 effect modes (`SetEffect`) are not exposed by the
  module API. No shutdown/exit packet exists upstream and none is sent.
* Upstream `Initialize` loops on `hid_read` until a 21-byte packet arrives;
  the module reads once and fails closed when no status packet answers
  (an unanswered device would otherwise block forever).
* Upstream `SendPacket` copies the second packet's colors from the start of
  `color_data` (not from the split offset); this exact behaviour is
  reproduced byte for byte.
* The module rejects accessory compositions larger than 40 LEDs: the
  upstream `SetLEDs` 120-byte `color_data` buffer and the 2x20-color packet
  pair cannot carry more, and an 8-strip Hue+ layout would overflow it.
* Firmware version string is built from bytes 0x0B/0x0E of the status
  packet and reported in the module capabilities.
