## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `EVisionKeyboardController.cpp :: SetKeyboardColors` | `report.rs :: v1_colors` + `lib.rs :: frame` | 126 LEDs as 7 sequential 0x36-byte chunks: `04`, command 0x11, size, offset LE, data at 0x08, checksum over bytes 3.. (no Begin/End packets in the color flow) |
| `EVisionKeyboardController.cpp :: ComputeChecksum` | `report.rs :: checksum` | 16-bit LE sum of bytes 0x03.. in bytes 0x01/0x02 |
| `RGBController_EVisionKeyboard.cpp :: SetupZones` | `lib.rs :: initialize` | single 126-LED keyboard zone, 6x23 matrix map (V1_MATRIX generated, LED 0 at the first mapped cell; the 22 unmapped LEDs take the first unused matrix cells deterministically), "Keyboard LED n" names |
| `EVisionKeyboardControllerDetect.cpp` + V2 detects | `devices_table.rs / table.rs` | all 15 REGISTER_HID_DETECTOR_IP rows (interface 1, usage page 0xFF1C); 13 V1 + 2 V2 rows |

## Changes

* Direct mode only; hardware effect modes not exposed by the module API.
* Audit corrections over the first branch version: 6x23 matrix layout replaced the
  fabricated 21x6 grid, the not-sent-upstream Begin/End packets removed, the V2
  rows de-claimed (keyvalue_map missing), interface/usage-page matching, generator
  script added.
* Upstream reads an echo after each write; the module transport performs the writes
  without blocking reads.
* Upstream sends no exit packets in the direct-color flow.
