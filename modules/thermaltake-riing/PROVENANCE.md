## Changes

* Direct mode only; hardware effect modes (Flow, Spectrum, Ripple, Blink, Pulse, Wave),
  Save/Fan packets and the Quad keepalive thread are not exposed by the module API.
* No serial number / firmware version reads.
* Zone sizes follow the upstream maxima (20 / 60 / 54 LEDs per channel) and honor the
  optional `initialize.zones` parameter; default is 1 LED per zone.
* Frames are sent once per frame on demand; upstream Quad sends keepalive buffers every 3 s.
