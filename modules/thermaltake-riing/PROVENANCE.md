## Behavior transfer

| Upstream file/function | Rust file/function | Behavior transferred |
|---|---|---|
| `ThermaltakeRiingController/ThermaltakeRiingController.cpp :: SendInit` | `report.rs :: init` | 65-byte packet `00 FE 33` |
| `ThermaltakeRiingController/ThermaltakeRiingController.cpp :: SendRGB` (PER_LED 0x18) | `report.rs :: base` | 65-byte packet `00 32 52`, port = channel+1, mode 0x18, GRB color data at byte 5 |
| `ThermaltakeRiingQuadController/ThermaltakeRiingQuadController.cpp :: SetChannelLEDs` | `report.rs :: quad` | 193-byte packet, mode byte 0x24 (`THERMALTAKE_QUAD_MODE_DIRECT`), GRB data at byte 5 |
| `ThermaltakeRiingTrioController/ThermaltakeRiingTrioController.cpp :: SetChannelLEDs` | `report.rs :: trio` | 65-byte packets, mode 0x24, byte 5 = 0x03, chunk id at byte 6 (i+1), GRB data at byte 8, chunk length 19, at least 2 chunks |
| `ThermaltakeRiingControllerDetect.cpp` | `devices_table.rs / table.rs` | All 51 HID detectors (Riing 0x1FA5-0x1FB5, Quad 0x2260-0x2270 + 0x232B, Trio 0x2135-0x213F + 0x2141-0x2145) |

## Changes

* Direct mode only; hardware effect modes (Flow, Spectrum, Ripple, Blink, Pulse, Wave),
  Save/Fan packets and the Quad keepalive thread are not exposed by the module API.
* No serial number / firmware version reads.
* Zone sizes follow the upstream maxima (20 / 60 / 54 LEDs per channel) and honor the
  optional `initialize.zones` parameter; default is 1 LED per zone.
* Frames are sent once per frame on demand; upstream Quad sends keepalive buffers every 3 s.
