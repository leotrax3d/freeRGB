## Changes

* Direct mode only; the ten effect modes (`SetChannelEffect`) are not exposed
  by the module API (Reset/Begin/EffectConfig stay unported; `SendReset` is
  kept as a byte-exact tested builder). No shutdown/exit packet exists
  upstream and none is sent.
* The upstream 1 s keepalive thread (re-commits while the last Commit is
  older than 1 s) is omitted: the module API has no timer threads.
* Upstream ignores the response reads after every write; the module skips
  them, except the firmware request which keeps its single read and
  tolerates a missing response exactly as upstream.
* Zones defaulting to 0 LEDs upstream become one LED per channel in the
  module (a zero-LED layout would be unusable); user sizes clamp to 40.
