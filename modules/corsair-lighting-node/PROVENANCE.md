## Changes

* Direct mode only; effect modes, TEMPERATURE/BRIGHTNESS/PROTOCOL packets and the
  firmware version read are not exposed by the module API.
* The 5-second keepalive Commit of the upstream KeepaliveThread is omitted; frames are
  sent on demand.
* Zone sizes follow the optional initialize `zones` parameter (default one LED per zone,
  upstream default is 0); clamped to the upstream maximum of 204.
* Audit corrections over the first branch version: plane/chunk packet order fixed to the
  upstream order (R, G, B per 50-LED block instead of plane-major), running start offset
  per block restored, one Commit per channel instead of a single trailing Commit, zone
  names "Corsair RGB Header N" instead of "RGB Header N", generator script added,
  `--list-devices` now filtered to supported devices and run mode restored.
