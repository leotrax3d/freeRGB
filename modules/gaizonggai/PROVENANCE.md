## Audit result

All 9 detector rows are inventoried, but `identify()` claims no device. The audited
branch version sent generic sequential chunks (packet commands 0x10.. with 20/21-byte
chunks) that match none of the upstream per-PID layouts:

| Upstream file/function | Notes for a future port |
|---|---|
| `GaiZhongGaiController.cpp :: SendColors` (68 PRO) | packets 0x10/0x11/0x12 with 63 bytes from offsets 0/21/42 plus 0x13 with 15 bytes; 2 ms delays |
| `GaiZhongGaiController.cpp :: SendColors` (42 PRO) | packets 0x10/0x11, 63 bytes from offsets 0/21 |
| `GaiZhongGaiController.cpp :: SendColors` (17 Touch/17/20 PRO) | single packet 0x10 with 60 (17/20) or 51 (17) bytes from offset 68 |
| `GaiZhongGaiController.cpp :: SendColors` (Dial) | packet 0x10, 63 bytes from offset 85 |
| `GaiZhongGaiController.cpp :: SendColors` (hubs) | up to 32 packets of 60 bytes, command byte 0..31 |
| `GaiZhongGaiController.cpp` destructor | restore packet `FF` |
| `GaiZhongGaiController.cpp` (LightBoard/HUB init) | flash read sequences 0x85/0x87/0x88/0x86 with 60-byte reads; LightBoard LED count and matrix shape come from the flash data |
| `RGBController_GaiZhongGai.cpp :: SetupZones` | fixed zone sizes (68/42/88/85/88/89) and per-PID LED name tables (led_names_general, led_names_42key, ...), matrix maps |
