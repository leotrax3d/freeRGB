## Audit result

All 3 detector rows (Streak, miniStreak, Streak65; interface 1) are inventoried, but
`identify()` claims no device because no Direct-mode path is fully ported:

| Upstream file/function | Audit finding |
|---|---|
| `FnaticStreakController.cpp :: SendRGBToDevice` (full/mini) | fragmented `SendRequest` framing: 65-byte write packets `00 <cmd> <total_len LE32> <offset LE32>` with 57 data bytes each, prefix `0F 03`, color buffer of 124/106 sequential RGB triplets; a 0x07 keepalive prevents mode revert (RGBController DeviceUpdateMode) |
| `FnaticStreakController.cpp :: SendRGBToDevice` (Streak65) | 64-byte write `0F 15` with `0F 03` at bytes 7/8, `FF` bytes 9..24, first-LED RGB at 25..27 |
| `FnaticStreakController.cpp :: GetLEDCount` | mini 106, full 124 |
| `RGBController_FnaticStreak.cpp :: DeviceUpdateMode` | keepalive required in direct mode |

The first branch version sent a fabricated feature report (64 bytes `0F 03 RGB`) for
a 1-LED layout on all three devices; it was removed.
