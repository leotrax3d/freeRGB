# Provenance

Ported from OpenRGB commit `bbc77470a7cba56af60989e54ba910d5ac66a3ac`,
`Controllers/CorsairCommanderCoreController/`. Detector data is generated by
`scripts/openrgb/port-corsair-commander-core-devices.mjs` (7 rows, interface 0,
usage page 0xFF42, usage 1).

## Ported: full Commander Core lifecycle - 7 detector rows

| Upstream file/function | Rust mapping | Behaviour |
|---|---|---|
| `CorsairCommanderCoreController.cpp` constructor packet-size selection | `lib.rs init_controller()` | V2 = 97 default; Core2 (0x0C32) V3 = 65; Core XT (0x0C2A) = 385; Commander Core (0x0C1C) with FW major 1 -> V1 = 1025; `command_res_size = packet_size - 4` |
| `SendCommand()` | `lib.rs send_command()` / `report::command_packet()` | 97/65/385/1025-byte write frame `[00 08 cmd0 cmd1 data...]`; reads until report byte 0x00; response slice starts at offset 3 |
| `InitController()` | `lib.rs init_controller()` | version query `[02 13]` res[0..2] = v major/minor/patch; V1 switch; SetFanMode(false) |
| `SetFanMode()` | `report::fan_mode_packet()` + `write_data()` | 15-byte payload `07 01 08` + `01 06` pairs; XT internal port shifts to index 2..13, XT external sets `01 01` and index 3; wake command `[01 03][00 02]` afterwards |
| `SetLedAmount()` | `report::led_amount_packet()` | `07 <amount>` payload (not used by the frame API; tested builder) |
| `GetLedCounts()` via `ReadData()` | `lib.rs read_data()` / `report::led_counts_from_response()` | open endpoint `[0D 00][20 00]`, read `[08 00]` (res from offset 3: count at res[2], little-endian words at res[5+4i]), close `[05 01]` |
| `WriteData()` | `lib.rs write_data()` / `report::data_packet()` | open endpoint, first packet `[len_lo len_hi 0 0 type0 type1 data...]` with real_len = data_len + 2, continuation `[07 00]` packets of `packet_size-4` bytes, close endpoint |
| `RGBController_CorsairCommanderCore.cpp` `SetupZones()` | `lib.rs initialize_with_zones()` | non-XT: "Pump" zone with LED count from endpoint 0x20 + 6 "Corsair Fan Header n" zones (default 0 LEDs, host-configurable up to 34); XT: "Corsair RGB Header" (0..204) + 6 fan headers |
| `RGBController_CorsairCommanderCore.cpp` `DeviceUpdateMode()` -> `SetDirectColor()` | `lib.rs frame()` / `report::rgb_buffer()` | RGB buffer 699 (XT 1224) bytes: 3 bytes per LED, after every zone except the first 3 bytes per unused LED up to 34; sent via WriteData endpoint `[22 00]`, data type `[12 00]` |
| destructor (hardware mode) | `lib.rs shutdown()` | `SendCommand([01 03], [00 01])` |

## Changes

- The 10 s keepalive thread and the 33 ms frame throttle are omitted; the
  freeRGB module API has no timer threads and frames are host-driven.
- Manual zone configuration for XT external RGB port (SetLedAmount /
  SetFanMode(true)) is not exposed by the frame API; the builders are ported
  and tested.
- `DEVICE_TYPE_MOTHERBOARD`-like device type maps to `LightingController`.
